Aqui você aprende sobre:

No curso técnico de DS (Desenvolvimento de Sistemas), aprendemos sobre a criação de sites, aplicativos e sistemas, utilizando linguagens de programação como: HTML, CSS, JavaScript e Python. Também estudamos bancos de dados, lógica de programação, desenvolvimento web e resolução de problemas. Além disso, desenvolvemos habilidades como criatividade, organização, raciocínio lógico e trabalho em equipe, importantes para criar soluções tecnológicas para o dia a dia.
